# 给「慢」下一个能算的定义

《学生"慢"科研联合声明》签署者的数据画像 —— 支撑 B 站视频《签了「慢科研」声明的人，反而更快？我详细统计了 109 位签署者的数据画像》的分析代码与结果。

- 数据快照：**2026-11-11**
- 课程：统计方法与机器学习（2026 秋）· 第 15 组 ML26-15 · Lab05

## 一句话结论

在这批签署者身上，「慢」不能靠"发得少"来度量——109 位可用签署者中位产出 **154 篇**、近五年中位 **18.2 篇/年**，年均低于 5 篇的只有 9 人。有区分度的是**注意力落在哪里、落多久**：相邻年份的研究主题只有 **37%** 重叠，而「深耕慢产」和「深耕快产」两个角落的人数几乎一样多（23 vs 33）。

**「慢」是一种形态，不是一个刻度。**

## 数据来源

| 数据 | 来源 | 规模 |
|---|---|---|
| 签署名单 | 《学生"慢"科研联合声明》签署页公开名单 | 120 人，消歧后 117 人 |
| 论文与主题 | [OpenAlex](https://openalex.org/) 公开数据库，按作者 ID 全量抓取 | 33,347 条作品（去重前） |
| 对照组 | 从签署者最高频的 30 个 OpenAlex 主题中各抽 12 位、总篇数 80–700 的研究者，排除签署者本人 | 355 位候选，292 位可用 |

原始 `works.json.gz`（约 3.5 MB）未随仓库提供，可用 `scripts/` 下的抓取脚本按 OpenAlex 公开接口重新获取。

## 指标定义

| 指标 | 定义 |
|---|---|
| 中位产出 | 每位作者去重后的作品总数 |
| 近五年年均 | 最近五个日历年的年均发表数 |
| 专注度 S | 主题分布的集中度（0–1，越高越集中在少数主题） |
| 团队规模 | 每篇合作者人数（含本人）的中位数 |
| 学术跨度 | 首篇到末篇的年数 |
| 单篇被引 | 被引总数 ÷ 作品数 |

两组比较：中位数差 + 95% 置信区间 + Mann-Whitney U 检验。

## 结果

| 指标 | 签署者中位 | 对照中位 | 差值 | p |
|---|---:|---:|---:|---:|
| 专注度 S | 0.373 | 0.265 | +0.108 | <0.001 |
| 近五年篇/年 | 18.2 | 8.3 | +9.9 | <0.001 |
| 团队规模中位 | 6.0 | 4.0 | +2.0 | <0.001 |
| 单篇被引中位 | 14 | 5 | +9 | <0.001 |
| 学术跨度（年） | 19.1 | 23.8 | −4.7 | <0.001 |

五个指标方向全部与预期相反：签署者每一项都更高。

三条值得单独说的发现：

1. **产出少的人并不更专注。** 年均 <5 篇的 9 人，专注度中位 0.167，低于年均 ≥30 篇那组的 0.392，被引中位也更低（5.5 vs 13）。更像是"离开了"而不是"沉下去了"。
2. **专注与高产不冲突。** 专注度 ≥0.5 的 28 人，近五年年均中位 19.6 篇，与整体 18.2 几乎相同。
3. **结论不是被极端值撑起来的。** 剔除产出最高的 5 / 10 / 20 人后，近五年年均中位分别为 17.6 / 17.2 / 15.0，方向不变。

## 局限（很重要）

1. **测量偏差对签署者有利。** 117 位签署者的 OpenAlex ID 是逐个人工核对的，对照组用的是默认聚类——默认聚类容易把一个人的成果拆到多个 ID，压低对照组的篇数、被引与专注度。偏差多大，本实验无法定量。
2. **仍是截面。** 对照组只提供参照尺度，不是反事实；不能推出"声明导致变化"，也不能推出"慢的人才去签"。
3. **领域未归一。** 样本以 CS/AI 为主但仍跨方向，绝对篇数不可跨领域比较。
