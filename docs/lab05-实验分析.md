## 一、这个实验在问什么

一件事：**给“慢”下一个可以计算的定义，然后拿它去量那一百二十个人。**

那一百二十个人，是《学生“慢”科研联合声明》的签署者。那份声明是 CS/AI 领域的教师和博导写给本科生的，内容大致三条：论文数量不是我们招博士的核心标准；短时间灌水式发表是减分项；科研的目的是能力塑造，不是论文。

签名的现有 120 位，大多是三维视觉、图形学、生成模型方向。他们同时承诺：在自己的实验室里，把培养独立思考放在产出之前。

实验要做的，就是拿公开数据回头查一遍——**说这话的人，自己到底慢不慢。**

## 二、要交什么

| 交付物 | 要求 |
|---|---|
| 指标设计说明 | 1–2 页 A4 PDF |
| 数据 | 抓下来的原始表 + 算出来的结果表，要能追溯 |
| 代码 | 能重跑出那张表的脚本 |
| 社交媒体链接 | 加分项，没有不扣 |

## 三、执行路径

1. **先把名单整理成 CSV**：姓名、职位、单位。
2. **消歧**：把每个人对上一个唯一的学术身份 ID。这是整份作业的真正技术难点。
3. **拉作品记录**：每人每篇的年份、标题、venue、合作者、主题。
4. **算指标、比较、写说明。**

## 四、指标怎么设计

题目明说没有标准答案，鼓励自己发明。几个站得住的方向：

**发文频率** —— 年均篇数、最长空窗期。简单，但必须按职业年限归一化，否则测出来的是“谁年纪大”。

**主题持续性** —— 相邻年份论文的主题相似度，或者主题分布熵。熵越低越专注；每年换一套词更像追热点。这一条最能抓到“慢”的真正含义：深。

**迭代节奏** —— 同一方向的系列论文之间隔多久。难点是“哪些算同一条线”要靠判断，判断规则必须写进说明书。

**单篇熟成时间** —— 预印本到正式发表的间隔。客观、难掺水。

**合作稳定度** —— 每年合作者集合的重合程度。长期只跟同一小群人做的，更像慢科研。

不必全做。挑一到两条主线，加一条辅助对照，把“为什么选它、它测不到什么”写清楚，比堆五个都做得浅更强。

## 五、数据源的实测情况

以下是在本机真实测试的结果，不是推测：

- **OpenAlex** —— 最合适。有稳定 author ID、精确发表日期、主题标签。但免费额度按 IP 共享，本机当日已耗尽（HTTP 429，UTC 午夜重置）。
- **DBLP** —— 作业推荐，但目前部署了 Anubis 反爬，Python 请求与无头浏览器均被拦截。
- **Semantic Scholar** —— 可访问，但作者消歧质量差：对 Angela Dai 只报 5 篇，实际约 125 篇。直接使用会得出荒谬结论。

**结论：优先申请 OpenAlex 免费 API key。**

## 六、真正的坑

**同名。** 名单里有多个 Qi Wu、Yue Wang、Chen Feng 这类名字，OpenAlex 上每个名字下都挂着几十个人。第一版程序把 Chen Feng（NYU）错配成 Feng Chen（另一学校，514 篇）。修正方案：姓氏精确匹配 + 名字首字母匹配 + 机构 token 校验。

**职业阶段不能混比。** 助理教授和讲席教授放一起排名，结论必然是“老的更慢”。需按首次发表年份做归一化或分层。

**时间窗口要统一。** 统一取 2015–2025，避免让 1998 年就有论文的人和 2020 年才开始的人比总数。

**相关性不是因果。** 是签了才变慢，还是本来就慢才去签？本实验无法回答。

**补充说明第三条要当真。** 数据是数据；结论可以尖锐，但不能写成对人的审判。
